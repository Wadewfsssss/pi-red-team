# pi-red-team

一个薄的 Pi 红队扩展：Pi 负责模型、原生工具、会话与压缩；插件补充证据、搜索、图辅助、可选协作和长作业监督。不围绕 Pi 再造 Agent 平台。

当前版本：**1.0.0-rc.10**，测试候选。仓库先以私有形式维护，尚未指定对外开源许可证，也未发布公共 npm 包。

## 安装

要求 Node.js 22.19.0+；已验证 Pi 1.4.0。仓库保留预编译 `dist`，普通 Git 安装不需要先构建 TypeScript。Pi 的 Git 包管理安装运行依赖，并使用宿主提供的 Pi SDK 与 typebox。

**在实际使用插件的终端环境中安装。** 在宿主执行就安装到宿主 Pi；要使用 Kali 工具，应在已有 Kali 容器内安装。插件安装不会下载 Kali 工具、构建镜像或启动 Neo4j。

私有 Git 仓库需要该环境已具备 GitHub 读取权限；不要把访问令牌打进镜像。固定版本安装：

```sh
pi install git:github.com/Wadewfsssss/pi-red-team@v1.0.0-rc.10
```

默认写入当前环境的个人 Pi 配置。若只希望登记到当前项目，可使用原生本地安装选项：

```sh
pi install --local git:github.com/Wadewfsssss/pi-red-team@v1.0.0-rc.10
```

安装后退出并重新启动 Pi。在授权工作目录中直接描述任务；不需要 `/rt open`、`.redteam/project.json` 或另一套任务系统。

检查安装登记用 `pi list`；检查实际加载用 `/rt status`。`pi --version` 只显示宿主版本。插件入口叫 `/rt`，不是 `/pi-red-team`，没有独立插件页面。

## 能力

| 入口 | 用途 |
| --- | --- |
| 原生 bash / 文件工具 | Pi 执行；插件自动保存证据、分类执行诊断、给出有界重复失败提醒 |
| `rt_search` | 证据关联的分支、TDA-EGATS 搜索决策、实际尝试与反馈；不是每条命令必经主控 |
| `rt_graph` | 利用原生 Neo4j MCP 做关系与路径辅助；不是全部动作必经的图状态机 |
| `rt_job` | Linux 前台长命令、增量输出、状态、取消、超时及不确定状态检查 |
| `rt_team` | 模型提出独立候选，经一次专家交互批准后，内部 Worker 自主认领、共享证据和增量交接 |
| `/rt doctor` | 检查实际环境能力，不执行目标扫描 |
| `/rt team status` / `stop` / `recover` | 检查与监督可选协作；未知执行不会自动重放 |

新会话直接描述目标。Pi 判断哪些工作自己执行、哪些适合并行；不要求用户先指定角色、Worker 数量或完整资产清单。成员容量默认 32、最多可批准 64；默认驻留／执行为 4、监督作业为 2，不是同时发送 64 个模型请求。

任务目的、范围和验收依据来自专家及外部规则。批次结束、无搜索候选或预算耗尽不等于整体成功。原始凭据和证据保留，工作目录应私有并受外部访问控制。

## 环境与配置

- 模型沿用 Pi 的 `~/.pi/agent/models.json`；不修改上下文、输出上限或 thinking。
- Neo4j 连接配置在 Pi 的原生 MCP 配置中；仓库不包含账户、密码或私人连接地址。
- Kali 是系统工具环境，独立于插件安装。安装本包不会自动安装 nmap、fscan、Ghidra 等。
- 长作业需要 Linux/Kali；宿主 macOS 的普通操作仍使用 Pi 原生工具。
- Pi 管理原生会话与压缩；不添加插件压缩循环或自动恢复未知命令。

## rc.10 可靠性边界

新作业停止等待终态提交与控制进程退出，并核对同 Linux 进程组及输出流收尾。shell 提前返回、仍有同组后台工作时回收并报告失败，不伪造完成。不要对监督的前台长命令额外加 `&`。

Worker 停止共用一次有界操作；停止或领域操作仍不确定时保留 attention。recover 不能抹掉已经记录的停止失败。新通知在交接消费期间到达时重新调度，仍受原会话与预算限制。

这些是生命周期与证据机制，不是漏洞裁判或 OS 沙箱。创建新会话的守护进程、控制进程崩溃、容器重启与多天运行不在无故障保证内。旧作业的控制进程级记录不追认为通过新子进程回收验证。

本版本借鉴 TDA-EGATS、图辅助推理及 Agensh / pi-subagents 的协作思路，并明确包含项目取舍，不声称完整复现论文基准或已经提高真实靶场解题率。参考实现不是本包运行依赖，也不启动其外部服务。

## 开发

```sh
npm ci --ignore-scripts --legacy-peer-deps
npm run typecheck
npm test
npm run build
```

开发 SDK 在 devDependencies，普通 Pi Git 安装只安装运行依赖。构建后的 `dist` 与源码一并提交，方便直接安装；不要只改源码而继续发布旧的 `dist`。

本仓库包含插件源码、编译产物、通用文档和隔离测试。没有上传旧主控、Kali 镜像、基准客户端、靶场数据、真实模型配置、密码、会话或执行日志。

母工程 rc.10 的技术门禁包含 142 次测试执行成功和真实隔离 Neo4j / Kali；这是先前完整环境的验证记录，不代表 Git 分发路径已经经过相同的整镜像验收。本仓库测试只运行自有临时数据与脚本化提供方；真实模型效果、多天稳定性和生产放行仍需另行验收。

第三方代码与许可证见 `THIRD_PARTY_NOTICES.md`。当前 `private: true` 用于防止误发布到 npm；不影响 Pi 的 Git 安装。
